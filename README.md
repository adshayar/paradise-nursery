# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shopping application.

Users can browse different categories of houseplants, view plant details,
add plants to a shopping cart, update quantities, remove items, and
calculate the total cost.

## Project Features

- Browse houseplants
- Multiple plant categories
- Add plants to cart
- Increase and decrease quantity
- Remove plants from cart
- Dynamic cart count
- Calculate total price
- Checkout option
- Continue shopping option

## Technologies Used

- React
- JavaScript
- CSS
- Redux Toolkit
- React Router
- Vite
